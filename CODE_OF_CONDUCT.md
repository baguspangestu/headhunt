# Code of Conduct

## Our standards

Headhunt welcomes constructive contributions from everyone. Participants are
expected to communicate respectfully, give actionable feedback, assume good
intent, and keep discussions focused on improving the project.

Unacceptable behavior includes harassment, discrimination, personal attacks,
threats, deliberate disruption, publishing another person's private
information, or sharing credentials and sensitive Import URLs.

## Enforcement

Project maintainers may edit or remove contributions, comments, issues, or
other participation that violates these standards. Repeated or severe behavior
may result in temporary or permanent exclusion from project spaces.

Report conduct concerns privately to the maintainer through GitHub. Do not use
a public issue when a report contains private or sensitive information. Reports
will be reviewed fairly and kept confidential as far as reasonably possible.

## Scope

This Code of Conduct applies in repository discussions, issues, pull requests,
and other spaces where someone is representing the Headhunt project.
